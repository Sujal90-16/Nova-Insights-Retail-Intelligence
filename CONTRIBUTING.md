# Contributing

Thanks for considering a contribution to Nova Insights.

## Workflow
1. Create a focused branch from `main`.
2. Install dependencies with `python -m pip install -r requirements.txt`.
3. Run `python -m pytest` and launch the dashboard locally.
4. Keep changes small and describe the motivation in the pull request.
5. Never commit secrets, private customer data, or unapproved production exports.

## Style
Prefer descriptive names, small functions, explicit assumptions, and reproducible analysis. Update documentation when a user-facing workflow changes.
