# Analysis Review Checklist

- [ ] Raw input files are unchanged.
- [ ] Date and numeric types are parsed intentionally.
- [ ] Cleaning counts are reported and explainable.
- [ ] Revenue formula and missing-profit assumption are disclosed.
- [ ] Monthly/category/region comparisons use consistent filters.
- [ ] Outliers are investigated, not silently discarded.
- [ ] Cluster features are scaled before distance-based clustering.
- [ ] Cluster count is supported by diagnostics and profile review.
- [ ] Conclusions distinguish description from causation.
- [ ] Charts include readable labels and units.
