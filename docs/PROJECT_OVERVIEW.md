# Project Overview

Nova Insights — Retail Intelligence Studio is a Python analytics project for exploring retail transactions and customer behavior. It combines a Streamlit dashboard, reusable data-cleaning and analytics functions, a sales analysis notebook, and generated reports.

## Main workflows
- Load transaction and customer RFM data.
- Inspect data quality and apply documented cleaning rules.
- Explore sales by date, category, product, and region.
- Compare customer segments produced by K-Means clustering.
- Review generated figures and executive summaries.

The bundled datasets are synthetic and should not be presented as real business results.
